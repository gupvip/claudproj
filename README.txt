Math Tutor
==========

A Python project for math tutoring tools. The application is currently under development.

Project contents
----------------
- src/jupyter/mathtutor.py: math tutor module (currently empty)
- requirements.txt: project dependencies

Setup
-----
1. Create and activate a Python virtual environment.
2. Install dependencies with: pip install -r requirements.txt

Testing
-------
Run the test suite with: pytest

Configuration
-------------
Keep credentials and local settings in a .env file. Do not commit .env; it is ignored by Git.
If you need to share required variable names, use a sanitized .env.example file without secret values.

Usage
-----
There is no application entry point yet. Add usage instructions here when the tutor functionality is implemented.
